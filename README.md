# COUNTER CORE - プロトタイプ開発ガイド

## 📋 このプロジェクトについて

**ジャストガード反撃型STG** - 敵弾を奪うシューティングゲーム

**核となるメカニクス**:
- パリィで敵弾をプレイヤー弾に変換
- ボスから敵弾を吸収して反撃
- 敵弾が増えるほど、奪う快感が増す

## 💡 注意点

### ジャストガード判定について

> **最も重要なのは「判定ウィンドウ」の大きさ**

- 小さすぎる（半径10px）: 難しすぎる → つまらない
- 大きすぎる（半径50px）: 簡単すぎる → 面白くない
- 目安: **半径 30px** から始めて、プレイして調整

### 敵弾の密度について

> **フェーズ3 で50発発射するのは、パリィで奪う快感を最大化するため**

- 敵弾が多い = 奪う敵弾も多い = 爽快感↑
- ただし、難易度も上がるので調整が重要
