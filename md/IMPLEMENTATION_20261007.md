# 5ステージ版の仕様・兵装・COUNTER実装報告

更新: 2026-10-07

この文書は捕獲追撃へ簡素化する前の実装履歴。現在は[捕獲追撃への改修報告](CAPTURE_REWORK_20261007.md)と[DESIGN.md](DESIGN.md)を参照する。以下の解析2枠・変異レベル・45組み合わせの検証は旧段階の記録であり、現在の戦闘ルールではない。

既存の5ステージと装備を活かし、仕様整合 → 兵装の実装 → COUNTER SYSTEMの順で改修した。現在の仕様の基準は[DESIGN.md](DESIGN.md)。体験は「大量の攻撃と派手な反撃による爽快感」を優先し、通常COUNTERはボス戦につき1回の大技とする。

## 実装した内容

### 仕様と進行

- 出撃時と再挑戦時に、保存された選択ステージを使用する。ステージ1への固定を解消した。
- 全5ステージを「75秒の解析 → 異なる変異兵装2枠を選択 → ボス1体」に統一した。ステージ5の旧第2ボスは起動しない。
- 解析の所有者をAnalysisSystemへ統一し、敵撃破オーブによる自動装備との競合を除去した。
- ステージごとの弾種から解析候補を設定し、10種すべてをキャンペーンで取得可能にした。候補不足時には、そのステージの候補から選択肢を補完する。
- 操作説明、装備画面、ラボ、HUDを実装へ合わせた。変更したキー設定を表示へ反映し、未実装の操作案内を削除した。
- ステージ変更後の遅延処理、敗北後のボス撃破通知、再利用した弾に残る旧タイマーを無効化した。

### 兵装

| 区分 | 実装した違い |
| --- | --- |
| マシンガン | 2射線の高速連射 |
| ライフル | 貫通弾の3点バースト |
| パルスガン | 3方向への射撃 |
| プラズマ | 低速重弾と着弾後の持続熱場 |
| タックル | 短射程の貫通衝撃波 |
| 変異兵装10種 | 連射、拡散、貫通、誘導、レーザー、波動軌道、着弾爆発、連鎖電撃、渦、弾切断 |

主兵装の発射方式を保ったまま、選択した2つの性質を加える。組み合わせ専用の攻撃が主兵装を上書きする旧処理と、実装に対応しない特殊融合名の説明を整理した。性能・説明の定義はWeaponCatalogへ集約した。

プラズマの熱場や範囲攻撃は、ボスの実際の衝突形状にも命中する。ボスの胴体とコア、複数グループへの所属による同一攻撃の重複加算を防いだ。変異兵装は弾道に加え、機体周囲の色とレベル表示でも確認できる。

### COUNTER SYSTEM

未充填・充填中・準備完了・発動中・使用済みをCounterSystemが管理する。ボス戦のパリィで充填し、手動で発動する。通常は1戦に1回。追加モードのCOUNTER ONLYでは、終了後に再びパリィで充填して手動発動する。

| COUNTER兵装 | 実際の攻撃 |
| --- | --- |
| 支援砲台部隊 | 左右2基によるビーム・誘導ミサイルの継続援護 |
| サイバーファンネル | 4機が敵砲台を優先して攻撃 |
| ギガエネルギー弾 | 巨大な低速弾で敵弾を消し、進路上へ多段攻撃 |
| 5連鎖スーパノヴァ | 画面幅に合わせた横断爆撃と、パリィ可能弾の3倍反射 |
| ギガレーザー砲台 | 前方の太い射線に沿う継続貫通攻撃 |
| ハイパーミサイル砲台 | 誘導ミサイルの6発斉射と着弾爆発 |

COUNTERの効果時間とHUDを連動させた。ポーズ中は残り時間を停止する。終了・敗北・再挑戦・ステージ変更時に、支援機と専用弾を停止・回収する。COUNTERによる反射や弾消しでは解析と再充填を増やさない。

## 容量と処理の整理

ゲーム本体のGDScriptは、HEAD版の675,017バイトから634,205バイトへ減少した。新しい実装を含めて40,812バイト、約6.05%の削減。改行をLFとして比較し、テストコードを除外した値であり、配布ファイル全体の削減率ではない。

休止中のプール弾は処理と衝突判定を停止し、再取得時に状態を初期化する。持続熱場は8個、渦は12個を上限とした。旧経験オーブの解析処理、未使用の兵装切替、共通フルバーストによる攻撃の上書きを整理した。

画像・音声の圧縮やエクスポート対象の削減は今回の改修には含めていない。次の容量最適化では、開発用の原画像・旧素材の配布除外、実際の表示寸法に対するテクスチャの縮小を優先する。削減量はエクスポート後に測定する。

## 音楽に頼らず強めたい体験

オリジナル音源を追加する前提を置かず、「奪う → 攻撃が変わる → 大技で敵の攻撃を崩す」という操作結果を見せる。現状では兵装の軌道差、機体周囲の表示、独立した6種類のCOUNTERをその土台として実装した。以下は次の演出案であり、追加実装済みの機能ではない。

1. **奪う瞬間を見せる。** パリィした弾から自機の装備枠へ短い光跡をつなぐ。何を取得し、次の射撃がどう変わったかを一続きに見せる。
2. **一度きりの大技に前後差を作る。** 発動時に装備が展開し、輪郭と射線が大きく変わる。反撃の命中と砲台破壊を強調し、派手な最中も危険弾と自機を見失わせない。
3. **壊した結果を残す。** 撃破した部位の発射位置が消え、ボスのシルエットが欠ける変化を強める。攻略によって弾幕が崩れたことを感じられるようにする。

まず短いボス戦で、この3点が音声なしでも伝わるかを確認する。通常攻撃とCOUNTERのダメージ量は、その試遊結果に合わせて調整する。
