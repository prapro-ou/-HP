# ゲーム・アイデアプール

ジャンルを横断し、COUNTER CORE の企画・画面・システムを考えるための参考資料。初版は68作品・8ジャンル。

## 開く

- **[IDEA_POOL.md](IDEA_POOL.md)**：エディタで読む、検索する、リンクをたどる。
- **[index.html](index.html)**：ブラウザで開くと、全文・ジャンル・雰囲気・欲しいアイデア・桜井さんの視点で絞り込める。
- 「可愛い」＋「画像」、「パーティ」＋「システム」などを組み合わせる。タグは各分類ですべて一致／どれか一致を切り替えられ、分類間は常にAND。
- ☆で候補を保存し、「お気に入りだけ」で戻る。ブラウザを替えると保存先も替わる。
- 行末の「見るポイント・最小試作」を開くと、観察ポイント、試作、公式画像、関連記事が出る。

一覧・検索はネット接続なしで動く。画像は公式の配信元から詳細を開いたときに読み込む。動画はリンク先の公式ストア／サイトで再生する。画像・映像の素材ファイルは同梱していない。

## このチャットでの企画相談の方針

「[桜井政博のゲーム作るには](https://www.youtube.com/@sora_sakurai_jp)」を主要な参照軸にする。特にリスクとリターン、緊張と解放、成功の手応え、視認性、駆け引き以外の面白さ、得になる攻略を考える。

動画の内容と、この資料の応用提案は区別する。各作品の星・タグ・試作案は編集判断であり、桜井さんがそのゲームを推薦したという意味ではない。作品の魅力をコピーするのではなく、何を感じてほしいかを整理し、小さく試して行動を観察する。

現行の [DESIGN.md](../DESIGN.md) の「敵弾を奪う」「性質を2つ重ねる」「部位を破壊する」「COUNTERを手動で決める」を応用の軸にする。音楽同期のゲームも参考にするが、同期やオリジナル音源を必須条件にはしない。

## 追加・修正

編集元は `catalog.json`（作品）と `editorial.json`（方針・記事・組み合わせ）。生成したHTML／Markdownの内容は再生成で置き換わるため、追加は編集元に行う。

1. `catalog.json` の `games` に1件追加する。IDは重複させず、作品名、ジャンル、タグ、公式リンク、特徴、持ち込む案、見るポイント、最小試作、試作負荷、参照する動画のIDを入れる。
2. `updated` を確認日へ更新する。雰囲気タグは複数付けてよい。「画像」「システム」などの欲しいアイデアのタグも必ず入れる。
3. Node.jsで `node md/idea_pool/build.mjs` を実行する。依存パッケージは不要。HTMLとMarkdownが同じデータから作られ、必須項目・ID・URL・JavaScript構文も確認される。
4. Steamの掲載メディアを更新したい場合だけ、`node md/idea_pool/collect-media.mjs` を実行してから再生成する。ネット接続が必要。HTMLを見るだけなら実行不要。

### データの見方

- `feature`：公式資料に基づく特徴。推測の仕様や現行版未確認の情報を断定しない。
- `idea`：COUNTER COREへ持ち込む編集提案。
- `watch`：動画や画像で確かめるポイント。全映像を視聴済みという表示ではない。
- `prototype` / `effort`：最小試作と相対的な負荷（低／中／高）。フルゲーム制作の工数ではない。
- `priority`：現行仕様との相性（1〜5）。ゲームの品質評価ではない。
- `principles`：`risk`、`release`、`impact`、`clarity`、`other`、`cheese`。
- `sources.json`：公式掲載情報の確認先とメディア件数。公式説明全文は再配布しない。

## 初版の確認範囲

2026-10-07に公式サイトとSteamの作品ページを調査。Steamの65作品は掲載APIから正式タイトル・スクリーンショット・動画の掲載を確認。任天堂の3作品は公式サイトを参照。開発者／公式記事は15件を収録。

動画は公式ページのプレイヤーへリンクする。配信形式がHLSのため、生の配信URLを『再生できる動画ファイル』として扱わない。リンク先の年齢確認、地域表示、外部配信状況は閲覧時に変わりうる。
