# ボス攻撃・シールド個性の試作

更新: 2026-10-08。ユーザーの直接指示により統括が今回の実装を担当。ゲーム本体へ接続済みの試作であり、難易度・威力・範囲の最終調整は未完了。

## ボス攻撃

既存攻撃の間へ新しい攻撃を追加。6回の本体攻撃のうち4回目と6回目に追加攻撃を行い、残りは既存の攻撃巡回を継続する。

| ステージ | 追加攻撃 |
| --- | --- |
| 1 | 隙間のある連続弾幕、照準を固定した連射 |
| 2 | 左右からの交差射撃、隙間のある連続弾幕 |
| 3 | 扇状の掃射、隙間のある連続弾幕 |
| 4 | 照準を固定した連射、扇状の掃射 |
| 5 | 左右からの交差射撃、隙間のある連続弾幕 |

- 0.75秒の予告を表示し、射線・弾幕の隙間を描く。追加弾はすべて捕獲可能。
- 狙い撃ちは予告開始時のプレイヤー位置へ固定する。発射直前の追い直しは行わない。
- 連続弾幕の隙間と掃射の向きは次の巡回で左右を切り替える。弾幕の隙間は同じ連射中に固定する。隙間はこの攻撃のものであり、他の砲台弾を無効化する安全地帯ではない。
- HP35%以下または砲台全破壊で連射数を増やし、「猛攻」と表示する。BREAK中は通常段階の弾数を保持する。
- 最後の発射後0.65秒は新シーケンスを維持し、次の本体攻撃を待たせる。既存砲台や接近迎撃は別の処理。
- シーケンスはボスの子として保持し、ポーズで停止する。死亡・操作ロック・ボス非表示・ステージ清掃で未発射弾を破棄する。

## シールド

| シールド | 試作で追加・変更した個性 | 維持した特徴 |
| --- | --- | --- |
| カウンターシールド | 捕獲に成功した展開で熱を8返す。最低0へ制限 | 追撃1.4倍、ヒート・空振りのリスク |
| 吸収マトリクス | 基本捕獲半径105→140。密集弾をまとめて取る | 基本再展開3秒、充填1.5倍、展開0.35秒 |
| 増幅ブースター | 成功時に半径125・基礎32ダメージの攻撃衝撃波。発光とBOOST残り時間を表示 | 成功後2秒の通常威力1.25倍、ヒート制 |

熱返却・衝撃波は1回の展開につき1回。追撃の保持と放出、回復やCOUNTER成功回数の集計は既存仕様を保持する。増幅の2秒間の効果は再捕獲で更新し、倍率は累積しない。

衝撃波は通常武器威力強化の倍率を適用し、近くの敵だけへ1回攻撃する。敵弾の消去・反射は行わない。COUNTER ONLYでは衝撃波を出さない。敗北・操作ロック・再挑戦でブーストと衝撃波表示を初期化する。

既存の装備ID、解放条件、購入済み強化と保存形式を保持。武器固有強化や恒久強化の整理方針は今回決定していない。
