# COUNTER CORE 現行仕様と試作状態

更新: 2026-10-10

ユーザー承認済みの軸は「防いだ弾が、そのまま自分の追撃になる」。既存の5ステージ・装備を活かし、大量の攻撃と派手な反撃による爽快感を優先する。通常COUNTERはボス戦につき1回の大技。音楽への同期やオリジナル音源を前提にしない。

この文書は現在の実装と未決定事項を区別して記録する。[V3_VERTICAL_SLICE.md](V3_VERTICAL_SLICE.md)は基本動作の回帰検証シナリオであり、キャンペーンを1ステージに制限するものではない。

## 攻撃と防御

1. 主兵装は出撃開始から自動射撃する。
2. パリィで敵弾を捕まえる。捕獲した弾が短時間、自機の周囲に集まる。
3. 次の射撃に合わせて、捕獲した弾を追撃として撃ち返す。

主兵装の発射方式は変えない。捕獲弾の種類・威力・色を値として保存し、追撃には誘導・貫通・爆発など元の種類に対応した効果を持たせる。敵弾がプールで再利用されても、保持中の追撃は変わらない。

現試作では最低0.26秒の表示後、次の主兵装の射撃で放出する。保持上限は12発。上限を超えた通常弾も防ぐが、追撃の追加は行わない。ガード不可の赤い攻撃は捕獲できない。捕獲は敵弾に対する操作であり、敵本体へ接触して取得する仕組みではない。

回復・パリィ回数・COUNTER充填の成功報酬は、シールドの1回の展開につき1回。同じ展開中に複数の弾を捕獲しても、報酬を弾数分だけ重複させない。5回の成功でHPを60回復する既存の修復は保持する。

保持中の弾はポーズ中に時間を進めない。敗北・勝利・ステージ変更・ボス前の移行で消去する。

被弾後の無敵は0.8秒。HP・被ダメージはこの短縮で変更していない。シールドの再使用時間とは別の設定である。

### 通常捕獲と精密捕獲

入力は同じシールド操作。外側リング内で通常捕獲、内側リング内で精密捕獲になる。内側半径は、シールド・範囲強化・フォーカスを適用した最終半径の2/3。精密捕獲はその弾の追撃威力だけを追加で1.25倍にする。

弾ごとに捕獲した瞬間の中心間距離で確定し、通常と精密を混ぜて保持できる。保持後に近づいても昇格せず、発射時にも倍率を掛け直さない。回復・COUNTER充填・熱返却・衝撃波の回数は精密でも増やさない。

二重リングと0.35秒の白金色の強調、短い「精密捕獲!」、短音で結果を示す。通常弾が大きく、中心が外側リングへ入る前に自機へ接触した場合も、展開中のシールドによる防御・捕獲を優先する。その弾の中心が内側に入っていなければ通常捕獲。ガード不可弾には適用しない。

## 進行

初回はステージ1で操作を学ぶ。以降は解放済みの5ステージから選び、主兵装・シールド・カウンター兵装を装備して出撃する。選択ステージと再挑戦先は一致する。

道中は有限ウェーブ。予約した敵がすべて出現し、生存敵がいなくなると次のウェーブへ進む。全ウェーブを突破すれば、60秒を待たずに2秒のボス警告からボス1体へ移る。捕獲は突破の必須条件にしない。

道中全体の上限は60秒。最初の敵の出現から計測し、ウェーブ間の0.65秒も含める。開始演出とボス警告は含めず、ポーズ・説明中は停止する。未処理の敵がいても時間切れで予約・敵・弾・捕獲弾を片付け、ボスへ移る。同じ瞬間の撃破と時間切れでは時間切れを優先し、遷移や報酬を重複させない。

中間ウェーブを突破して次へ進むとHP+30/TP+10を1回だけ得る。時間切れで飛ばした境界と最終ウェーブ→ボスには追加報酬を与えない。通常の敵撃破・ボス報酬と強化費用は維持する。

| ステージ | ウェーブ数 | 有限の出現数 | 中間突破の報酬回数 |
| --- | ---: | ---: | ---: |
| 1・2 | 3 | 各11体 | 各2回 |
| 3・4 | 3 | 各13体 | 各2回 |
| 5 | 4 | 17体 | 3回 |

移動哨戒、縦列、横分散と低速密集を既存の敵で構成する。道中データに指定された敵だけ、高度・横移動幅・進入速度を保つ。初期装備での敵の射撃・捕獲追撃と、縦列への貫通、横分散への3方向射撃、密集への熱場を活かす。敵のHP・武器威力をこの改修で変えない。練習とボス支援は従来のAIを使う。強化済みの射撃で敵が撃つ前に倒れることを、必ず防ぐ仕様にはしない。

ボス前の解析2枠選択と、戦闘中の変異レベル育成は接続を外している。旧ステージ5の第2ボスは起動しない。出撃中の主兵装切替は行わない。

## 主兵装と捕獲弾

| 主兵装 | 役割 |
| --- | --- |
| マシンガン | 直進2射線の高速連射。安定した攻撃 |
| 3点バーストライフル | 高威力・貫通の3点バースト。縦の敵列への攻撃 |
| パルスガン | 3方向への射撃。横に広がる敵の制圧 |
| プラズマ放射器 | 低速重弾と着弾後の持続熱場 |
| キネティックタックル | 前方至近距離への貫通衝撃波 |

捕獲弾には直進・拡散・貫通・誘導・レーザー・波動・爆発・電撃・渦・刃の10種類がある。拡散は3方向、電撃は近くの敵への連鎖、渦は着弾地点の範囲攻撃、刃は通常の敵弾の切断として働く。武器を恒久取得して主兵装へ重ねる旧方式から、捕まえた分を一度だけ消費する追撃へ変更した。

性能・説明・敵弾との対応はWeaponCatalogを定義元とする。10種類の旧AnalysisWeaponリソースは対応表として再利用している。旧AnalysisSystemとLoadoutDraftは本番シーンに接続しない。図鑑は実際に捕獲した種類を記録する。

## シールド

| シールド | 捕獲後の特徴 | 再使用方式 |
| --- | --- | --- |
| カウンターシールド | 追撃威力1.4倍、成功時に熱を8返却 | ヒート制 |
| 吸収マトリクス | 基本半径140、COUNTER充填量1.5倍 | 基本3秒の再展開時間 |
| 増幅ブースター | 近距離衝撃波と成功後2秒間の主兵装威力1.25倍 | ヒート制 |

増幅ブースターの衝撃波は基本威力32・半径125で、主兵装威力強化を反映する。1展開で1回。2秒の効果時間は更新し、威力を累積しない。既存のフォーカス3設定は捕獲範囲と追撃威力の交換として保持する。精密捕獲はその設定内での捕獲位置の判定であり、追加の設定・キーを設けない。

## 自機の強化（暫定の整理）

現試作はラボでの恒久強化を中心にする。既存のHP・パリィ範囲・冷却・シールド範囲・COUNTER威力と持続時間・装備解放を保持し、「主兵装威力」と「捕獲追撃威力」を追加した。

| 強化 | 試作値 |
| --- | --- |
| 主兵装威力 | 1段階ごとに+8%、最大+40% |
| 捕獲追撃威力 | 1段階ごとに+12%、最大+60% |
| 上記2項目の費用 | 初回12TP、以後1段階ごとに+10TP、各5段階 |
| 冷却 | 1段階ごとに放熱速度+10%、オーバーヒートと再展開時間-8% |

捕獲追撃の基礎威力は、元の敵弾威力（最低12）の2.2倍。追撃強化・シールド・フォーカス・精密捕獲の倍率を捕獲時にそれぞれ1回適用する。これらの数値は試遊前の暫定値である。COUNTER威力強化の最大は1.8倍で、ラボのMAX表記もこの値に合わせている。

旧セーブのTP・装備解放・既存強化・図鑑を保持する。新しい強化項目がないセーブではLv.0として読み取る。ラボの購入で選択ステージを初期化しない。

## COUNTER SYSTEM

ボス戦中のパリィで充填し、通常出撃ではボス戦につき1回だけ手動発動する。CounterSystemが充填中・準備完了・発動中・使用済み・戦闘外を管理する。

充填は成功1回で22、連続成功の補正は最大+8。標準シールドで4回連続成功すると100に達する。充填不足・戦闘外・発動中・使用済みでは発動しない。

支援砲台、ファンネル、ギガエネルギー弾、5連鎖爆撃、ギガレーザー、ハイパーミサイルの6種類は、それぞれ別の攻撃として働く。支援砲台・ファンネル・ミサイルは基本10秒、レーザーは基本6秒、5連鎖爆撃は基本1.5秒。持続時間強化は各兵装へ同じ比率で適用する。巨大エネルギー弾は画面外に出た時点で終了する。

ポーズ中は残り時間を停止する。終了・敗北・再挑戦・ステージ変更で効果・専用弾・支援機・HUDを戻す。COUNTERによる反射や弾消しでは自機操作のパリィ回数や充填を増やさない。

COUNTER ONLYは追加モード。主兵装と捕獲追撃を停止し、パリィで弾を消してCOUNTERを充填する。大技を繰り返せるが、毎回新たな充填と手動発動が必要。

道中では通常・ONLYともCOUNTERを充填しない。ONLYでも道中の上限60秒を使い、ボス戦から従来の再充填を行う。

HARD限定化は比較案のままで、今回実装していない。通常のNORMALでもCOUNTERを使用できる。

## 戦闘シミュレーター

オプションから開始する練習用の別入口。本編の5ステージ進行は変更しない。現在の装備・強化・難易度・COUNTER ONLY設定・操作設定を使う。

| 設定 | 挙動 |
| --- | --- |
| ドローン | 既存11種から選ぶ。1体の単発、または2秒間隔の補充で同時3体まで |
| ボス | クリア済みのステージ1〜5のみ。旧セーブの次ステージ解放によるクリア推定も本編と同じ判定を使う |
| ボスHP | 無限。通常はHP100%、激化はHP30%相当の攻撃段階で固定する |
| 自機HP | 有限、または無限。無限でも被弾反応・一時無敵・ガード破壊は発生する |
| 再挑戦・退出 | 同じ条件で再挑戦、練習設定へ戻る、オプションへ戻る |

ボスの砲台破壊・修復・BREAK・支援ドローンは働く。通常モードのCOUNTERは練習でも1戦1回で、再挑戦により初期化する。COUNTER ONLYの反復発動は維持する。

練習中はTP・スコア・ステージクリア・解放・図鑑・TIPS・初回説明の進行を更新しない。セーブと設定のファイル書き込みも抑止する。開始前の進行・装備・設定を保存し、退出時に復元する。再挑戦・敗北・退出で保持弾、熱、COUNTER、操作ロック、予約攻撃を片付ける。

## 操作と伝達

移動はWASD・方向キー・設定キー。シールドは設定キーまたは右クリック。COUNTERは設定キー。ESCで一時停止。キー表示は現在の設定を参照する。

HUDは左上にHP・シールド状態、右上にウェーブまたはボスHP、左下に捕獲数、右下にCOUNTERを表示する。BOOSTは独立表示し、シールドの使用可否を隠さない。捕獲数0では追撃の「待機」を出さず、保持中だけ精密弾数を補助表示する。COUNTERは発動中にも残り秒数を表示する。旧BEAM/MISSILE枠は削除している。

道中HUDは`WAVE 現在/総数`、予約分を含む残り敵数、`上限 MM:SS`を表示する。間隔中は`次へ`。開始演出・初回説明・装備画面・TIPSでも「撃破で突破 / 最大60秒」を伝える。

警告は上部の短い共通帯に集約し、ガード不可を砲台・BREAK・通常予告より優先する。長いキー名は戦闘HUDだけBksp・PgDnなどに短縮し、設定画面の正式表記を保持する。

本文・HUD・設定はM PLUS 1 Code、短い大見出しと成功表示はDotGothic16を使う。新しい字体とOFLを配布パックへ同梱する。敵のstraight・wave・chargeはドットテイストの別外形を持ち、chargeの0.4秒の溜め発光はシアンから白金へ変化する。攻撃AI・当たり判定は画像の変更を理由に変えない。画像はNearestフィルタで描画する。

捕獲弾専用の蓄積ゲージやレベル表示は追加しない。捕獲した弾は種類に応じた輪郭で描き、敵弾とは自機周囲の配置と明るい縁で区別する。

音楽以外の体験は「弾を捕まえる → 自機に集まる → 撃ち返して命中する」という操作結果を見せることから作る。ボスの砲台破壊やCOUNTERの大きな展開変化も、この因果関係を強める。

## 未決定・未確認

- 強化をラボ中心に絞るか、旧2枠・レベルの要素を残すかは質問中。現実装は前者の試作であり、最終決定済みとしない。
- 次の自動射撃で撃ち返す基本案は承認済み。追加質問で出した「防御ボタンを離した時に放出」との比較は未回答。最低表示時間・保持上限などは暫定調整値。
- 精密範囲2/3・追加1.25倍は今回の実装値。武器の個性、最大強化の実戦火力、精密を待つ見返りは試遊で調整する。
- ヘッドレスの回帰テストと、視認性・入力の手触り・火力バランス・負荷時FPS・5ステージの通しクリアは別に扱う。後者は試遊が必要。
- 道中の通常30〜45秒は調整目標。自動試験で時計と早期突破を確認しても、人間の突破時間を測定したことにはならない。
