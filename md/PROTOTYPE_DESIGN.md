# ジャストガード反撃型STG - プロトタイプ設計

## プロジェクト概要
**目標**: 反撃によって敵の攻撃を奪い、武器として再構成する体験の検証

**核コンセプト**: COUNTER CORE
- プレイヤーは弾を避けるだけではなく、敵弾を「奪う」ことで反撃を強化する
- ジャストガード成功時に敵弾を自機弾に変換し、最終的には武器DNAが変異する
- つまり「避ける」ではなく「奪う」ことが主戦術になる

**スコープ**: 巨大ボス1体 + ジャストガード反撃のコアループのみ

**検証期間**: 敵弾を奪う快感と、反撃がゲーム全体を変える感覚が成立するか

---

## 検証優先順位

| 優先度 | 項目 | 検証内容 | 成功条件 |
|--------|------|--------|--------|
| **① 最重要** | ジャストガードの気持ちよさ | パリィのタイミング・フィードバック | クリティカルに触れたい感覚がある |
| **② 次** | 敵弾を奪う楽しさ | パリィで敵弾が自機弾・反撃に変化する体験 | 「もっと奪りたい」という欲望が生まれる |
| **③ その次** | ボス単体での5分体験 | 巨大ボスが主役で、反撃の連鎖が成立するか | 攻撃パターンの周期性と変化が面白い |
| **④ 後回し** | 武器変異・ビルド拡張 | ただしプロトタイプでは最小限だけ実装 | 核が完成してから拡張する |

## ゲームフロー（プロトタイプ版）

```
ゲーム開始
  ↓
巨大ボス出現（フェーズ1）
  ↓
【メインループ】
├─ ボスが敵弾を発射
├─ プレイヤーが移動・射撃しながら敵弾を捉える
├─ 敵弾に接近しジャストガード判定ウィンドウに入る
├─ パリィ成功 → 敵弾を奪い、反撃用の自機弾へ変換
├─ 反撃が溜まる → 武器が一時的に変異する
├─ パリィ失敗 → ダメージ
└─ ボスの攻撃密度が増え、奪う価値が上がる
  ↓
ボスHP 0 → ゲーム終了（勝利）
プレイヤーHP 0 → ゲーム終了（敗北）
```

## システム設計

### 1. プレイヤー機体

**操作**:
- 移動: WASD または 矢印キー
- 射撃: マウスクリック または スペースキー
- ジャストガード: 敵弾が接近したタイミングで自動判定

**パラメータ**:
- HP: 100
- 移動速度: 300 px/s
- 自動射撃: 毎フレーム前方に弾発射
- ジャストガード判定ウィンドウ: 敵弾中心から半径 30px 内
- 反撃ゲージ: パリィ成功ごとに増加

**ジャストガード時の動作**:
1. 敵弾の速度ベクトルを反転
2. 敵弾を自機弾へ変換
3. 反撃ゲージを増加
4. 反撃ゲージが一定値に達すると武器が一時変異
5. パーティクル・SE でフィードバック

---

### 2. 巨大ボス

**名前**: 古代神（暫定）

**外観**: 画面上部中央に固定された巨大な敵機体

**攻撃パターン**:

| フェーズ | 敵弾数/サイクル | 発射パターン | 周期 |
|---------|-------------|----------|-----|
| 1 | 5発 | 扇状（前方5方向） | 2秒 |
| 2 | 15発 | 円形（全方向） | 1.5秒 |
| 3 | 50発 | 画面全体弾幕 | 1秒 |

**HP**: 3 フェーズ分岐（各フェーズ 300HP）

**フェーズ遷移**:
- HP 200 以下 → フェーズ2 へ（弾幕密度増加）
- HP 100 以下 → フェーズ3 へ（全画面反撃のチャンス）

---

### 3. 敵弾システム

**敵弾オブジェクト**:
- 速度: 200 px/s
- 半径: 10px
- 所有権: 敵 or 味方
- 反撃変換時に「敵の攻撃エネルギー」がプレイヤーの武器へ移る

**パリィ判定**:
- プレイヤーから敵弾中心までの距離 ≤ 30px → パリィ判定ウィンドウ内
- ウィンドウ内の敵弾を「タッチしている」状態
- フレーム単位で判定（自動パリィ）

**ジャストガード時の変換**:
```
敵弾（敵所有）
  → パリィ判定ウィンドウに入る
  → 速度反転（敵→自機への方向）
  → 所有権を味方に変更
  → 反撃ゲージ増加
  → 武器変異条件を満たすと変異発動
```

## コアループの強化案

### 1. 敵弾を「資源」にする
プロトタイプでは、敵弾は単純な障害物ではなく、反撃の燃料になる。

- 1回のパリィで 1unit の反撃エネルギーを獲得
- 反撃ゲージが一定値に達すると、武器が一時的に変異
- 変異内容の例:
  - 通常ショット → 連射強化
  - 反撃弾 → 追尾弾化
  - 連続パリィ → 画面全体反撃

> 重要な点は、「避ける」ではなく「奪う」が主軸になること。

### 2. ボスがプレイヤーを育てる
ボスの攻撃が激しくなるほど、プレイヤーが反撃で得る力も増える構造にする。

- フェーズ2: パリィで反撃ゲージが増えやすい
- フェーズ3: 弾幕を奪って一気に反撃が炸裂する
- 最終形態では「全部奪う」ことで超反撃が発動する

### 3. 反撃で武器が変異する
この方向性が最も強い。敵の攻撃を吸収し、その性質を自機の武装へ転写する。

- レーザー型の攻撃を奪えば、レーザー武器が獲得できる
- ミサイル型の攻撃を奪えば、追尾武器が獲得できる
- ただしプロトタイプでは、まずは「連射・拡散・追尾」の一部だけを実装する

## 世界観設計

### 主人公機
**COUNTER CORE**

古代文明の遺構に残された試作兵器。敵の攻撃エネルギーを逆流させることで、
敵の構えた弾幕を自機の反撃兵装へ変換する。

この設定により、以下が自然に説明できる。
- 敵弾を吸収する
- 反撃する
- 武器が変化する

つまり、システムと世界観が一致する。

## 実装のポイント

### パフォーマンス
- 敵弾数が最大50発 × 複数サイクル → オブジェクトプーリング必須
- BulletPool.gd で敵弾を再利用する

### ジャストガード判定の品質
- 判定ウィンドウ（半径30px）の大きさはプレイヤーが納得するまで調整する
- 小さすぎると難しく、大きすぎると一瞬で奪える
- 反撃の快感が上がるように、タイミングの余韻を強くする

### ボス攻撃の周期性
- 敵弾が単調なら飽きるため、フェーズごとにパターン変化を入れる
- ボスの見た目・色・演出で、反撃の盛り上がりを演出する

---

## 成功の定義

このプロトタイプが成功する条件は、以下の3点が両立していることです。

1. ジャストガードのタイミングが心地よい
2. 敵弾を奪う快感が味わえる
3. ボス単体でも5分は遊べる

特に重要なのは、次の一点です。

- プレイヤーが「弾を避ける」より「弾を奪う」方が楽しいと感じること
