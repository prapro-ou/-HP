# 狭幅UIと現行セーブ初期化の修正

更新: 2026-10-10 / 担当: 開発

ユーザー承認「不具合先になおして」に基づく、有限ウェーブ完了後の次の1件。作戦選択・TIPSのはみ出しと、通常の全セーブ初期化を本番コードへ接続し、必要な検証・描画・引き継ぎまで完了した。

## 修正結果

- 作戦選択の下部4ボタンを画面内の可変幅に配置。長い説明・難易度・タイトルを折り返し、Stage5 HARDでも詳細枠が横へ広がらない。
- 選択中カードの拡大に必要な左右余白を確保。固定のカード幅・間隔によるスクロール計算を実際の配置へ変更し、画面幅変更後のスクロール範囲更新も待つ。先頭・末尾を含む選択中カードを切らない。
- TIPS左列を画面幅に合わせて調整。分類は横スクロール、一覧と詳細はそれぞれ縦スクロール。長い一覧タイトル、空分類の案内、詳細文を折り返す。開いたままの比率変更にも対応する。
- 捕獲弾図鑑の長い見出し・項目を折り返す。最後の項目と閉じるボタンまで表示・操作できる。
- 通常の初期化は `Global.SAVE_PATH`（`user://savegame_v3.cfg`）だけを削除し、成功後にメモリを初期状態へ戻す。保存がない場合も成功する。旧名 `savegame.cfg`、設定、無関係ファイルを削除しない。
- 削除失敗時は進行状態とファイルを保持し、確認画面に「削除できませんでした。データは保持しています。」を表示する。キャンセル、デバッグON・練習中の拒否も保持する。
- クリア済みステージ、HARD、装備COUNTER、初期COUNTER解放など、初期化漏れを修正。設定は保持し、再起動でも進行が復活しない。
- 初期化確認と初回チュートリアル確認の中央配置を修正。現行メニューには独立したCONTINUEボタンはなく、既存の「出撃開始」を維持し、初回チュートリアルへ進むことを確認した。

作戦選択の色指定は編集前と一致する。承認済みの明るめ配色・字体・ドット表現を維持した。HP、被弾後無敵0.8秒、有限道中、兵装、COUNTER、練習・精密のルールは今回変更していない。

## 確認結果

Godot 4.7.1の専用コピー `.godot/implementation_check` で順番に実行。本体の `SAVE_PATH` と `SETTINGS_PATH` は変更せず、コピーだけ `res://verification_save.cfg` / `res://verification_settings.cfg` へ分離した。Globalはこの2定数以外、本体と一致。他の今回対象コードとテストも一致する。本人の実セーブを試験に使っていない。

- 最終インポート: EXIT=0、スクリプトエラーなし。
- `test_responsive_ui.gd`: 675/800/900×1200、全5ステージNORMAL/HARD、未解放、フォーカス、前後矢印、戻る・図鑑・ラボ・出撃準備、全TIPS分類・一覧選択・閉じるを実入力で確認。画面とスクロール枠の境界検査を実施。TIPSを開いたまま900→675→800へ変更しても操作部と選択中カードが収まる。
- 図鑑とTIPS詳細でマウスホイールが動作し、末尾が読める。長文の検証用データを一時表示して詳細の縦スクロールを確認した。製品のTIPSカタログは変更していない。
- 通常の削除・削除失敗・設定から戻る・新規出撃も実クリックで確認。3比率で確認画面と操作ボタンが収まる。
- `test_save_reset.gd`: 新規オブジェクトの初期値と25個の進行項目を比較。削除後の再読込、Stage1出撃、HP500/無敵0.8秒、初期装備・解放を確認。キャンセル、保存なし、保存先がディレクトリの場合、デバッグON、練習中の拒否を確認。
- Windowsで実際に保存ファイルを開いたまま削除を試み、削除失敗・ファイルとメモリ保持・通知を確認。ファイルを閉じて再度削除すると成功する。
- `test_save_reset_restart.gd`: 次の別プロセスでもStage1/TP0/初期装備・解放を維持し、クリア・HARD・ONLY等が復活しない。設定、旧名ファイル、無関係ファイルが保持される。
- 回帰: `test_debug_tools.gd`、`test_simulator_precision.gd`、`test_finite_waves.gd`、`test_campaign_combat.gd`、`test_pause_settings.gd`。専用3本と合わせて8本すべてTEST_OK、エラーなし。
- 作戦選択の色指定を編集前と比較して一致。対象の `git diff --check` は問題なし。

最終描画は66枚（各比率22枚）。全ステージNORMAL/HARD、未解放、図鑑先頭/末尾、空TIPS・一覧選択・現行最長TIPS・長文検証先頭/末尾、初期化確認/失敗、初回出撃を保存した。675/800/900の代表画像を直接目視確認した。未選択の隣接カードや横スクロール中の分類の一部はスクロール枠で隠れるが、選択中カードと各分類への切替・末尾到達は確認済み。
