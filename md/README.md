# COUNTER CORE - 開発プロジェクト

本作は「避ける」のではなく「奪う（パリィ）」ことを主戦術とする、ジャストガード反撃型シューティングゲームです。

## 新仕様ドキュメント

ゲームの全体仕様、武器やシールドのカスタマイズ、敵の個性、特殊技研（ラボ）などの詳細設計については以下を参照してください。

*   **[DESIGN.md](DESIGN.md)** - 現行5ステージ版の実装・画面・説明の基準
*   **[TERMINOLOGY.md](TERMINOLOGY.md)** - ゲーム内用語・HUD表記・文章量の基準
*   **[assets_guide.md](assets_guide.md)** - アセット配置・機体カラー設定ガイド
*   **[github_management_guide.md](github_management_guide.md)** - GitHub運用・管理ガイド
*   **[team_management_guide.md](team_management_guide.md)** - チーム管理ガイド
*   **[PARALLEL_WORK.md](PARALLEL_WORK.md)** - アイデア・開発・デザイン・統括の担当範囲と合流ルール
*   **[idea_pool/IDEA_POOL.md](idea_pool/IDEA_POOL.md)** - 68作品の特徴・モチーフ・システム・公式動画／画像／記事をまとめたアイデアプール（[タグ検索HTML版](idea_pool/index.html)）

## プロジェクト目標

ジャストガードによる敵弾の反撃体験をさらに深化させ、多彩な武器・シールドの組み合わせ、ボスの部位破壊、音声アシストAI、およびラボによる能力強化などを備えた本格的なSTGゲームを構築します。
