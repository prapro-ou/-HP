# COUNTER CORE 用語・表記ガイド

ゲーム内の名称と文章を統一するための基準です。新しい文言を追加するときは、この文書を先に更新します。

## 1. 最優先で管理するもの

用語集では、次の順にまとめます。

1. **プレイヤーが操作判断に使う語** — パリィ、ガード、ガード不可、オーバーヒートなど
2. **画面に常駐する語** — HP、解析率、スロット、残り時間、撃破数など
3. **成長・装備の語** — 主兵装、変異兵装、シールド、カウンター兵装、TPなど
4. **敵と攻撃の分類** — 直進弾、追尾弾、レーザー、砲台、コアなど
5. **固有名詞** — ステージ名、ボス名、兵装名、組織名など

固有名詞を増やす前に、操作判断に使う語の意味が一意になっていることを優先します。

## 2. 基本用語

| 正式表記 | HUD表記 | 意味 | 使わない表記 |
|---|---|---|---|
| ガード | GUARD | シールドで攻撃を防ぐ通常防御 | 防御、ブロック |
| パリィ | PARRY | タイミングよくガードし、敵弾を反射・解析する操作 | ジャストガード、パリィ反射 |
| ガード不可 | 回避！ | ガードとパリィができない攻撃 | ガード不可能攻撃、GUARD IMPOSSIBLE |
| オーバーヒート | OVERHEAT | シールドを一時的に使用できない状態 | 加熱、シールド停止 |
| 主兵装 | WEAPON | 通常射撃に使う装備 | メイン武器、基本武装、初期武器 |
| 変異兵装 | MUTATION | 敵弾の解析で主兵装に加わる特性 | 解析兵装、変異属性 |
| 解析 | ANALYSIS | パリィした敵弾のデータを蓄積すること | スキャン、吸収蓄積、解析強化 |
| 解析率 | 数値 + `%` | 変異兵装を獲得・強化する進捗 | 解析度、解析ゲージ |
| 変異スロット | SLOT | 変異兵装が固定される2つの枠 | 解析枠、属性枠 |
| カウンター兵装 | COUNTER | ゲージを消費して使う特殊兵装 | 必殺システム、ボス武器 |
| テックポイント | TP | 機体強化に使う通貨 | 開発ポイント、解析技術ポイント |
| 砲台 | TURRET | ボス本体を守る破壊可能部位 | サブ砲台、ボスタレット |
| コア | CORE | ボス本体の主要部位 | 本体コア、要塞コア |

## 3. 表記ルール

- 日本語の正式表記を基本にし、英語は短いHUDラベルと演出に限る。
- 同じ意味の言葉を言い換えない。特に「パリィ」と「ジャストガード」は併用しない。
- `Lv.2`、`HP`、`TP`、`90秒`のように、数値と単位の間は空けない。
- 感嘆符は重要な警告または成功演出で1つまで使う。
- `【】`、`[]`、全角記号を重ねて強調しない。色、サイズ、余白で階層を示す。
- 敵や兵装の固有名詞は、初出時だけ正式名称を表示する。戦闘中は役割名を優先する。

## 4. 画面別の文章量

| 表示場所 | 目的 | 上限の目安 | 例 |
|---|---|---:|---|
| 自機付近のポップアップ | 即時結果 | 12文字・1行 | `解析 +12%` |
| 戦闘中の警告 | 次の操作 | 16文字・1行 | `ガード不可 — 回避！` |
| ウェーブ開始 | 状況と目標 | 2行、各20文字 | `追尾弾が増加` / `パリィして突破せよ` |
| ボス登場 | 敵名と攻略要点 | 2行 | `ガーディアン接近` / `砲台を先に破壊` |
| 解除通知 | 獲得物と次の行動 | 2行 | `ギガレーザー解放` / `装備画面で選択可能` |
| 一時停止・TIPS | 詳細理解 | 制限なし | 数値、例外、背景説明を記載 |

## 5. 戦闘中テキストの書き方

戦闘中の文章は、状況説明よりもプレイヤーが次に行う操作を優先します。

- 悪い例：`惑星中枢防衛セキュリティが最大稼働！チャージボルトと誘導弾の嵐をパリィで制圧せよ！`
- 良い例：`チャージ弾・追尾弾が増加` / `パリィして突破せよ`

削る順番は「飾りの形容詞」「重複する世界観説明」「既知のシステム説明」「丁寧語」です。AIアシストの人格は語尾の長さではなく、短い観測と命令の型で表現します。

## 6. 追加時の確認項目

- この語は既存語と同じ意味ではないか
- プレイヤーが操作判断に使う語か、設定を読むための語か
- 戦闘中に全文を読まなくても意味が通るか
- HUD表記とTIPS内の正式表記が対応しているか
- 表示時間と文字サイズで実際に読み切れるか
