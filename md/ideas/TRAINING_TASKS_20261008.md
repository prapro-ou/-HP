# 二段階パリィを学ぶ3つの練習課題

更新: 2026-10-08。担当: アイデア。

**実装への引き継ぎ資料。課題の配置・文言・達成目安は独自提案で、接続・試遊は未実施。** 二段階パリィと練習モードの実装方向は、[統括の「デザイン整理と実装の開始」](../parallel/COORDINATION.md)に従う。本体・確定仕様はこの資料で変更しない。

目的は「まず防ぐ」「まとめて返して射手を止める」「先に倒すか、引きつけて強く返すか」を、既存のstraight・wave・chargeで順に学べること。専用のミッション進行、報酬、ランキングを追加する要件ではなく、既存の練習対象と配置で再現できる3つの試遊手順とする。

## 共通の前提と、先に伝えること

| 項目 | 今回使う前提 |
| --- | --- |
| 操作 | 通常射撃は自動。通常捕獲も精密捕獲も同じシールド入力。表示するキーは現在の割り当てを参照する |
| 判定 | 最終捕獲半径をR、内側を2R/3とする初期比較値。捕獲時に内側へ入っている弾の追撃だけ追加1.25倍。最終値は開発の確認後に記録する |
| 入力の意味 | **外側で捕まえた弾は、待っても精密に変わらない。** 精密を狙う時は、展開前に弾を内側まで引きつける。押しっぱなしで内側へ届くのを待つ練習にしない |
| 出撃前フォーカス | 既存のSTANDARD（半径100%・追撃1倍）、FOCUS（75%・1.2倍）、PINPOINT（50%・1.4倍）を維持。戦闘中の精密判定とは別の選択 |
| 反撃 | 捕獲弾は最低0.26秒の表示後、次の通常射撃で自動放出。別の「撃ち返すボタン」は説明しない。追撃は基本前方へ飛ぶため、成功後に射線を合わせる |
| 成功報酬 | 1展開で通常・精密・複数弾が混ざっても、修復・COUNTER充填・熱返却・攻撃衝撃波はそれぞれ現行の1展開1回。精密で修復回数や充填量を追加しない |
| 捕獲量 | 保持上限12発。あふれた分の防御と、実際に保持された追撃の数を混同しない。発射後の拡散3射線も「捕獲3回」ではない |
| 対象・HP | 雑魚は単発／無限補充、ボスはクリア済みのみ・HP無限固定、自機は有限／無限HP。最初は無限HPで入力を覚え、同じ課題を有限HPで確認する |
| 本編との関係 | 練習のTP・スコア・クリア・解放・図鑑・チュートリアル・保存は本編へ加算しない。現在の装備・購入済み強化を使い、比較では変更しない |

初心者への共通文言案: **「早めに展開すると通常捕獲。内側まで引きつけて展開すると強い追撃。捕まえた後は、敵の下へ移動して撃ち返そう。」** 遅れた被弾や通常捕獲を、すべて精密の失敗として扱わない。危険なら通常捕獲や回避を選んでよい。

## 課題一覧

| 順番・対象 | 学ぶ判断 | 最初の構成 | 成功が分かる結果 |
| --- | --- | --- | --- |
| 1・straight | 外側で安全に捕まえる／引きつけて内側で捕まえる | マシンガン＋カウンター、STANDARD | 同じ敵弾で通常と精密を見分け、追撃までつながる |
| 2・wave | 弾をまとめて捕まえる／広い弾幕を作る射手を止める | パルス＋吸収、STANDARD | 1展開で複数の弾が集まり、反撃後に新しい波状射撃が止まる |
| 3・charge | 溜め中に先に倒す／射線を外して強い弾を待つ | マシンガン＋カウンター、STANDARD | 発射前撃破と、発射後の強い反撃を別の試行で選べる |

構成は解放済みの場合の比較例。練習のために未解放装備を本編へ解放した扱いにしない。未解放なら現在の装備で課題を行い、推奨構成は説明と後の比較に使う。最初からPINPOINTや全弾精密を要求しない。

## 課題1: 直進弾を「防ぐ」から「引きつけて返す」へ

### 設定と配置

- straightを1体、基本は無限補充ON。自機HP無限から始め、理解後に有限で再確認する。
- 射手を画面上側、自機を下側に置き、初期位置を真下から少し横へ外す。既存の狙い撃ちを使い、自動の前方射撃だけで最初の捕獲機会が消えない配置を確認する。
- 現行のstraightは狙った方向へ0.1秒間隔で3発を撃つ。方向は射撃開始時に決まる。追尾弾ではなく、1発だけの攻撃でもない。敵の移動も現行のまま使う。

### 必要な行動

1. シールドを使える状態で、近づく弾を見る。最初の試行は弾が外側のリングに入った時点で展開し、通常捕獲から自動追撃までを見る。
2. いったん展開を終え、熱や再使用状態を確認する。次の射撃では、**まだ展開せずに**先頭の弾を内側まで引きつけてから同じキーを押す。
3. 捕獲後は敵の下へ射線を合わせ、追撃が出て命中する場面を見る。狙い撃ちの射線へ無理に戻り続けず、残りの敵弾も確認する。

### 成功したと分かる結果

- 通常では「通常捕獲」、内側では「精密捕獲」に対応する表示・光・音が出る。表示案は通常「捕獲・追撃待機」、精密「精密捕獲・強追撃待機」。実際の文言はデザインと開発のHUD整理に合わせる。
- 同じ弾種・強化・フォーカス・シールド条件で、通常追撃と精密追撃をそれぞれ確認できる。命中時の距離補正や整数化があるため、敵HPの減少量だけで必ず正確に1.25倍と判定しない。
- 3発すべてを精密にする必要はない。先頭が精密、後続が通常になる混在も正しい結果。外側で捕まえた先頭弾が後から精密表示になるのは誤り。

### 練習で確認する点

**課題の成立条件は「通常を1回、精密を1回見分け、どちらも追撃へつながる」こと。** これは試遊の目安であり、新しい自動達成判定の実装を必須にしない。

開発は、表示された内外の境界と捕獲距離が合うか、同じ展開で成功報酬が増えないか、通常から精密へ格上げされないかを確認する。自動射撃で敵が先に倒れる場合は配置と最初の射撃開始を調整候補にし、主兵装停止や雑魚の無敵化を課題の前提にしない。

## 課題2: 波状弾をまとめて返し、弾幕を作る敵を止める

### 設定と配置

- 基本はwaveを1体、単発で射撃と撃破前後の違いを見る。その後、無限補充ONで同じ捕獲を反復する。
- 現行のwaveは下方向へ5本の扇状弾を同時に撃つ。距離が離れるほど弾間隔が広がるため、広い吸収シールドでも全5発の捕獲は保証しない。
- 画面中段寄りで、中心側の弾を**同じ展開中に2発以上**取れる捕獲機会を作る。半径・画面比率・敵の移動・強化条件に合わせて開発が位置を確認する。敵本体へ接触して取りに行かせない。
- 混成配置を既存の仕組みで用意できる場合だけ、wave1体＋straight1体を左右に分けて比較する。初心者の同時出現は最大2体。混成選択や同期射撃を初版の必須追加にしない。

### 必要な行動

1. 横へ広がる攻撃を見て、中心側の弾が重なる位置へ移動する。最初は通常捕獲でよく、すべて精密にするために危険な位置へ近づかない。
2. 吸収を1回展開し、複数弾が自機へ集まる様子を見る。追撃を射手へ向け、その後は再展開まで回避する。連打で待ち時間を消せるとは説明しない。
3. 単発設定ではwaveを優先して倒し、次の波状射撃が来なくなることを見る。混成の場合は、straightの射撃が残っていても波状の広がりが減る違いを比べる。

### 成功したと分かる結果

- 1回の展開で複数の保持弾が見え、放出時にwave由来の拡散追撃が広がる。捕獲1発から出る3方向の追撃と、捕獲した敵弾の数を別に読み取れる。
- 射手を倒すと**その敵からの新しい射撃**が止まる。すでに発射された敵弾は残るため、撃破後も回避が必要と分かる。
- 無限補充では次のwaveが現れるが、画面の敵数を増やし続けず、同じ機会を反復できる。単発の「撃破で射撃が止まる」観察と、補充による次の射撃を混同しない。

### 練習で確認する点

**課題の成立条件は「複数捕獲から追撃へつなぎ、射手を倒すと次の弾幕が減ると分かる」こと。** パルス＋吸収で横の敵を拾いやすいか、再展開待ちに退避できるかを見る。マシンガン＋カウンターへ替えた同条件の比較では、捕獲量と1発の威力のどちらを取りたいか説明できればよい。最強構成の順位づけはしない。

開発は、波状弾が広がり過ぎて実際には1発しか取れない配置、自動射撃で射手が先に消える配置、補充直後の弾幕が休む機会をなくす配置を確認する。全弾捕獲のための新AIや強制停止から始めない。

## 課題3: 溜め撃ちを先に止めるか、強い弾を奪うか

### 設定と配置

- chargeを1体、単発で2通りを比較し、無限補充ONで反復する。初めは自機HP無限、判断を覚えたら有限で行う。
- 現行のchargeは0.40秒の溜め後、狙った方向へ0.15秒間隔で2発の強い弾を撃つ。弾速はstraightより速い。発射前の点滅・砲口やコアの予告を判断材料にする。
- 自機を射手の真下から少し横へ外し、「狙いを合わせて倒す」「自動射撃の射線を外して待つ」の両方ができる余地を残す。雑魚を生かすために射撃停止ボタンを新設しない。
- chargeの赤橙色の機体や点滅と、**捕獲できない赤い攻撃**を混同させない。この敵の通常charge弾は捕獲対象。捕獲可否は弾の輪郭・予告・状態で区別できるか、デザインと開発が確認する。

### 必要な行動

1. 安全策の試行では、敵の下へ射線を合わせ、溜め中を含め発射前に倒すことを狙う。倒せない時は回避や通常捕獲へ切り替える。遅い武器でも必ず0.40秒で倒せるという条件にはしない。
2. 強い反撃の試行では、射線を少し外して発射を待つ。先頭弾を見て、まず通常捕獲。慣れたら内側まで引きつけて精密捕獲を狙う。溜めの点滅と同時に早押しするだけでは精密にならない。
3. 成功後に射線を合わせ、貫通追撃を返す。2発目が残っていれば回避し、熱や再展開待ちも見る。無条件に接近を続けない。

### 成功したと分かる結果

- 安全策では、発射前撃破によってその射手の強い弾が出ずに済む。すでに出た1発目まで消えた扱いにしない。
- 反撃策では、charge由来の貫通弾が保持され、放出後に命中する。精密なら同じcharge弾の通常捕獲より追撃威力が増える。
- 初期コードの元弾威力はstraight/waveが10、chargeが18で、捕獲追撃の計算には最低12が使われる。**同じ条件でchargeを奪う見返りがある**ことは説明できるが、総火力・撃破時間・一撃撃破を未測定のまま保証しない。

### 練習で確認する点

**課題の成立条件は「先に倒す安全策と、発射を待って返す策を別々に試し、危険なら前者を選べる」こと。** 精密だけを正解にしない。速い弾で内側に引きつける余裕、0.40秒の予告の読み取り、自動射撃で待つ相手を倒してしまわない位置を確認する。

同じ課題の装備比較として、バーストなら縦の射線と発射前撃破、タックル＋増幅なら捕獲直後の短い接近を見られる。増幅の衝撃波が射手を先に倒した場合、追撃がその射手へ命中しなくても機能不全としない。接近の見返りは衝撃波・BOOST・追撃を分けて確認する。

## 装備の役割を3課題へつなぐ

[既存の構成レビュー](LOADOUT_CHOICES_20261008.md)は維持する。以下は今回の練習で見る場所の整理であり、数値調整・既存装備の削除・強化リセットの提案ではない。

| 主兵装 | 練習で見える役割 | 相性と残る制約 |
| --- | --- | --- |
| マシンガン | 課題1の基準。捕獲に集中し、成功後に前方射線を合わせる | カウンターの強い追撃と比較しやすい。自動射撃で練習相手を早く倒す場合は横へ射線を外す |
| 3点バーストライフル | 課題3の発射前撃破、既存の縦配置で貫通を見る | 強い単体攻撃と縦列向き。横に離れた相手や射線ずれは残る。全弾命中を前提にしない |
| パルスガン | 課題2で横へ散った敵を拾い、移動場所を作る | 吸収のまとめ取りと相性を比較。3方向すべてが単体へ当たる保証はない |
| プラズマ放射器 | 課題3で敵の位置へ重弾と熱場を置く | 射手が熱場に留まる場合の継続攻撃。弾は遅く、溜め開始から必ず発射前に倒せるとはしない |
| キネティックタックル | 課題3の成功後に短く近づいて攻め、また離れる | 増幅の2秒BOOSTを比較。これは短射程の射撃で、自機のダッシュではない。移動距離180の弾と、半径125の衝撃波は別の届く範囲 |

| シールド | 練習で見える役割 | 成功後の行動 |
| --- | --- | --- |
| カウンター | 課題1・3の1発の強さ。追撃1.4倍と1展開の熱8返却 | 射線を合わせて返す。使用熱22があるため連打の保証にしない |
| 吸収 | 課題2の広域捕獲。基本半径140・展開0.35秒・基本再展開3秒 | まとめて返して待ち時間は回避。充填1.5倍はボス練習での追加利点で、準備までの秒数とは別 |
| 増幅 | 課題3の成功直後の攻撃機会。主兵装1.25倍が2秒、近距離攻撃衝撃波 | すでに近い敵を短く攻める。衝撃波は弾消しではなく、遠方の敵には当たらない |

無限HPでも被弾の認識を残し、強い構成で危険を無視した結果と、有限HPで安全に判断できた結果を分ける。COUNTERは雑魚課題の達成手段にせず、現行のボス戦条件を維持する。HARD限定化は今回採用しない。

## フォーカス比較と接続後の確認

まずSTANDARDの同じ装備・強化・敵・自機HP条件で3課題を行う。その後、課題1だけを同条件でFOCUS／PINPOINTに替え、リングが狭くなる代わりに同じ捕獲弾が強くなることを確かめる。フォーカス変更と精密成功を同時に変えた火力を、精密だけの効果として説明しない。

参考となる未強化の半径計算（外側R／内側2R/3、画面上の中心距離の比較値）:

| シールド | STANDARD | FOCUS | PINPOINT |
| --- | --- | --- | --- |
| カウンター | 85／約56.7 | 63.75／42.5 | 42.5／約28.3 |
| 吸収 | 140／約93.3 | 105／70 | 70／約46.7 |
| 増幅 | 75／50 | 56.25／37.5 | 37.5／25 |

強化があれば最終Rから計算する。自機と敵弾の衝突形状、フレーム間の移動、接触と捕獲の順序があるため、数値上の半径だけで最狭設定の安全性を保証しない。精密の追加倍率は保持した弾へ一度だけ適用し、放出時に重ねて適用しないことを開発が確認する。

接続後のレビューは、各課題の成立条件を同じ条件で観察し、次の項目を短く記録すればよい。専用グラフや新しい保存データは必須にしない。

| 記録する項目 | 判断すること |
| --- | --- |
| 装備・強化・フォーカス・HP・補充設定 | 同条件で比較できるか |
| 通常／精密の見分け、保持に入った弾数と混在 | 入力と結果が伝わり、1展開の報酬重複がないか |
| 追撃の放出・命中、捕獲前に射手が死んだ場面 | 自動射撃を維持したまま課題が成立するか |
| 被弾・熱・再展開待ちと、危険時に選んだ行動 | 精密の見返りとリスクが釣り合い、通常捕獲や回避も選べるか |
| 射手撃破前後の新しい射撃と残留弾 | 敵を倒す意味と、撃破後の危険を区別できるか |

クリア済みボスを選べるようになったら、同じ「安全に防ぐ／引きつけて返す／射手を止める」の判断を、砲台・BREAKとCOUNTERの使い所で確認する。課題を追加したり、ボスを有限HPへ変更したりする要件ではない。HP無限固定でも砲台破壊や段階攻撃をどう再現するか、COUNTER・残留弾・予約攻撃・熱・捕獲を再試行時に戻せるかは開発の接続確認に委ねる。

本編75秒と終了条件は今回変更しない。以前の道中3編隊・45秒案は[個性の10案](IDENTITY_IDEAS_10_20261008.md)に残る採用未決定の比較候補であり、この練習資料から本編の採用済み仕様へ移さない。
