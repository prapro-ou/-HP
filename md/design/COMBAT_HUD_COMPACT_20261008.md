# 戦闘HUD整理案: 上端2列＋下端アクション

作成: 2026-10-08

## 目的と前提

応募まで約1か月で接続できるよう、現行ノードと表示条件の整理を中心にした1案。新しい常設ゲージや新規素材は増やさない。

- 道中75秒の後にボス戦へ移行する。
- 通常射撃は自動。パリィした弾は最大12発を捕獲し、最低0.26秒保持した後、次の通常射撃へ追撃する。
- 現行COUNTERはボス戦で充填し、手動発動する。
- COUNTERをHARD限定にする案は採用未決定。本資料では同じHUDの難易度差分として扱う。
- 共有UI、既存シーン、戦闘ルールは変更していない。

## 情報の優先順位

1. 攻撃予告とガード不可警告。今すぐ回避行動を変える情報。
2. HPとシールド使用可否。生存とパリィ可否を決める情報。
3. 道中の残り時間、またはボスHP。現在の目標と区切り。
4. 捕獲数と保持状態。次の自動射撃の結果を予測する情報。
5. COUNTERの使用可能状態。ボス戦で能動入力につながる情報。
6. BOOST残り時間。攻める判断の補助情報。

攻撃予告は中央の敵弾や射線そのものを主情報とし、文字は短い補助に留める。弾種一覧、撃破数、常時の操作説明は戦闘中の主要HUDから外す。

## 1案の配置

画面幅を `W`、高さを `H=1200` とする。左右余白12px、中央間隔12px、上段の列幅は `(W - 36) / 2`。2:3、3:4、9:16で同じアンカーと表示順を使う。

```text
┌────────────────────────────────────────────┐
│ [HP・SHIELD]          [TIME または BOSS HP] │ 上段 12～82px
│                                            │
│       [短い攻撃予告 / ガード不可警告]       │ 88～126px
│                                            │
│                 戦闘領域                    │
│        自機・敵弾・射線を常に優先            │
│                                            │
│ [CAPTURE 0/12]       [COUNTER: HARDのみ]    │ 下端 1118～1188px
└────────────────────────────────────────────┘
```

### 左上: 生存・防御カード

- 範囲: `x=12`、`y=12`、幅=`(W-36)/2`、高さ70px。
- 1段目: `HP 500 / 500` と現行HPバー。
- 2段目: 現行シールドバーと状態文言。`SHIELD READY [キー]`、`SHIELD 展開中`、`SHIELD 再展開 2.4s`、`OVERHEAT 1.6s`のいずれか1つ。
- BOOST中はシールド文言を置換せず、2段目右端の小さな金色バッジで `BOOST 1.8s` と表示する。
- 主兵装名は開始時・装備変更時の短い通知へ移し、常設しない候補。戦闘中に切り替えないため優先度が低い。

### 右上: 現在目標カード

- 範囲: `x=W-12-列幅`、`y=12`、幅=`列幅`、高さ70px。
- 道中: 1段目 `WAVE 2`、2段目に大きく `00:42`。撃破数は常設しない。
- ボス: 1段目 `BOSS  7500 / 7500`、2段目に現行ボスHPバー。
- 道中からボスへ切り替える同じ枠なので、同時表示と座標競合を発生させない。

### 上中央直下: 行動警告帯

- 範囲: `x=12`、`y=88`、幅=`W-24`、高さ38px。
- 通常の攻撃予告は暗色半透明背景に、短い攻撃名と行動だけを表示する。例: `交差射撃 — 隙間へ`。
- ガード不可時は同じ帯を赤へ切り替え、`ガード不可 — 回避！` とする。別の警告を重ねない。
- 警告帯の透明度は低くし、既存の射線、弾幕の隙間、自機を隠さない。画面中央の大型説明はボス接近など戦闘遷移時だけに限定する。

### 左下: 捕獲カード

- 範囲: `x=12`、`y=H-70`、最大幅260px、高さ58px。
- 0発: `CAPTURE  0 / 12`。補助文は出さない、または小さく `捕獲なし`。`追撃待機`は禁止。
- 1～12発: `CAPTURE  5 / 12`、2段目 `保持中`。追撃タイミングを説明する必要がある初回だけ `次の通常射撃で追撃` を短時間表示する。
- 放出時: カードへ新しいゲージを加えず、数値を0へ戻す。放出の手応えは既存の自機周囲の捕獲弾と発射演出を主にする。
- COUNTER ONLY表示が必要な現行仕様では `捕獲追撃 OFF` とし、存在しない0発を「待機」と表現しない。

### 右下: COUNTERカード

- 範囲: `x=W-232`、`y=H-70`、幅220px、高さ58px。
- 充填中: `COUNTER  63%` と現行バー。
- 使用可能: 金色で `COUNTER READY [キー]`。常時の全画面通知は行わず、READYになった瞬間だけ0.4秒のリングパルス。
- 発動中: 同じ枠を `COUNTER ACTIVE  4.2s` へ置換。現行のようにACTIVE中だけ枠を消さない。
- 使用済み: `COUNTER 使用済み` を低彩度で表示。ボス戦中に再充填しないルールが確定している場合だけ残す。
- 道中では非表示。NORMALでCOUNTERを使わない案を採用した場合も非表示。

## NORMALとHARDの差分案

HARD限定COUNTERは採用未決定。採用する場合も配置を作り直さない。

- NORMAL: 右下COUNTERカードを常に非表示。通常射撃、パリィ捕獲、次弾追撃へ注意を集中させる。COUNTERの操作説明も出さない。
- HARD: ボス戦だけ右下COUNTERカードを表示し、充填、READY、ACTIVE、使用済みを同じ枠で遷移させる。
- HARD限定にしない場合: 現行どおりボス戦で表示する。その他のHUD配置・文言は同じ。

## HARD向けCOUNTER演出案: 二重リング反転

新規画像を作らず、既存の発光、リング、画面フラッシュ、軽い画面振動を再利用する。

1. 開始: 0.25秒でシアンと金の二重リングが自機へ収束。画面色は最大でも薄い着色に留め、右下を`ACTIVE`へ切り替える。
2. 主命中: ボス位置で二重リングを外向きへ反転し、0.12秒の白金フラッシュと短い振動を1回。敵弾と攻撃予告線は消さず、前面を不透明な画像で覆わない。
3. 終了: 自機側のリングを0.25秒で拡散・消去し、着色を戻す。右下を`使用済み`へ切り替える。

強力さはリングの大きさ、発光の色変化、命中時の一回だけの強調で示す。長時間の全画面白飛び、連続振動、大きな中央文字は避け、自機、敵弾、攻撃予告を見失わせない。

## 3画面比率での収まり

| 内部解像度 | 上段1列の幅 | 判定 |
| --- | ---: | --- |
| 2:3 `800×1200` | 382px | HP／目標カードに十分。捕獲260pxとCOUNTER220pxの間に296px残る |
| 3:4 `900×1200` | 432px | 最も余裕がある。同じフォントサイズを維持し、カードを無理に横へ拡大しない |
| 9:16 `675×1200` | 319.5px | 左右2列が12px間隔で収まる。下段260px＋220px＋左右余白で171px空き、中央の自機視界を確保できる |

9:16を基準に文言を短くし、2:3・3:4では余白だけを増やす。画面比率ごとの別レイアウトは作らない。現行のボスHP固定開始位置`x=280`や捕獲固定幅340pxは使わず、左右アンカーと列幅から配置することを開発へ提案する。

## 修正優先点（最大3点）

1. **旧枠と上部競合を除去:** `BEAM SYSTEM`、`MISSILE SYSTEM`を非表示または削除し、道中時間とボスHPを右上の同じ枠へ統合する。捕獲は左下へ移す。
2. **捕獲文言を事実に合わせる:** 0発は`CAPTURE 0/12`、1発以上だけ`保持中`。存在しない追撃待機を表示しない。
3. **同時状態を隠さない:** SHIELD使用可否を主表示として残し、BOOSTは小バッジ、COUNTERはボスの右下、ガード不可は警告帯へ分離する。各情報を別の常設ゲージに増やさない。

## 開発へ渡す表示条件

- WaveTimerPanelとBossHPは排他的に同じ右上カードを使う。
- CapturePanelは常設してよいが、0発時は1行に縮小できる。`shots.size() > 0`だけ保持文言を表示する。
- BOOSTはGuardStatusLabelを置換せず、独立した小ラベルの表示・非表示だけで扱う。CapturePanelへBOOST文言を重複させない。
- TopWarningはHP・目標カードの下へ置き、ガード不可中は他の文字警告を置換する。射線・弾幕の描画は維持する。
- CounterPanelは道中で非表示。ボス中は難易度方針に応じて表示し、ACTIVEも同じ枠で示す。
- 旧BeamSlotとMissileSlotを本番から外す際は、参照元が残っていないか開発が確認する。

## 静的確認と未確認

確認済み:

- 現行`ui.tscn`に`BEAM SYSTEM [0%]`と`MISSILE SYSTEM [0%]`が残る。
- 現行捕獲表示は0発でも`追撃待機`を付ける。
- 現行9:16描画でHP、ボスHP、捕獲、攻撃予告が上部に密集し、旧2枠とCOUNTERが下部左右に分散する。
- 現行コードではBOOSTがシールドの状態文言を置換し、捕獲詳細にも重複して表示される。
- 現行CounterPanelはACTIVE中に非表示となる。

未確認:

- 実機フォントで319.5px列へ最長の日本語状態文言が収まるか。
- マウス、キーボード、ゲームパッド各キー名の最大幅。
- 手動試遊時に自機周囲の捕獲弾だけで放出を認識できるか。
- 新しいボス攻撃名とガード不可警告が同時発生した時の優先切替。
- COUNTERをHARD限定にする最終判断、1回制か再充填制か、強力な大技へ変更する場合の実時間。

Godotのインポート、戦闘テスト、保存データ試験は行っていない。本番への接続と3比率での描画確認は開発担当へ引き継ぐ。
